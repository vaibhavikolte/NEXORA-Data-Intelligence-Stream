# NEXORA – Data Intelligence Stream

NEXORA is a Python-based data cleaning and analytics application built with Streamlit.

## Features
- Upload CSV and Excel files
- Preview datasets and inspect column types
- Handle missing values and duplicate records
- Generate before-and-after data quality reports
- Analyze sales data when compatible date and sales columns are available
- Generate basic sales forecasts when sufficient monthly data is available
- Export processed data to Excel and SQLite

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- OpenPyXL
- SQLite

## Run Locally
1. Install Python.
2. Install the required packages using `requirements.txt`.
3. Run the application:

```bash
streamlit run app.py
```

## Project Purpose
NEXORA demonstrates data cleaning, data quality validation, exploratory sales analysis, basic forecasting, and data export in one application.
